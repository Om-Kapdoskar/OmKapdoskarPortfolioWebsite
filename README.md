# Om Kapdoskar — Personal Portfolio (Next.js App Router + Tailwind CSS + Framer Motion)

High-performance, responsive personal portfolio website for **Om Kapdoskar**, built with Next.js 14 (App Router), React 18, Tailwind CSS, Framer Motion micro-interactions, and Lucide React icons.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view in your browser.

## Included Assets & Structure
- `/public/assets/om-kapdoskar.jpg` — High-resolution Virginia Tech graduation photo
- `/src/app/layout.tsx` & `/src/app/page.tsx` — Next.js App Router entrypoints
- `/src/components/PortfolioClient.tsx` — Modular sections (`Navbar`, `Hero`, `SocialQuickStrip`, `About`, `Skills`, `Projects`, `Experience`, `Education`, `Contact`, `Footer`, `ProjectModal`, `ResumeModal`, `CursorGlow`, `TiltCard`)
